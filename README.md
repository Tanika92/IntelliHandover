# IntelliHandover

### AI-Powered Project Knowledge & Employee Handover System

IntelliHandover is an AI-powered desktop application designed to make employee project handover easier and more organised.

The system helps capture and organise project-related information from a selected project folder so that a new employee can understand the existing project workflow without depending completely on manual explanation from the previous employee.

---

## 🎯 Problem Statement

When an employee leaves a company, the new employee often depends on the previous employee to understand the project's files, workflow, progress and important information.

This manual handover process can take a lot of time and may result in loss of important project knowledge.

IntelliHandover aims to reduce this dependency by automatically monitoring and organising information from a user-selected project folder and providing an AI assistant for project-related queries.

---

## 💡 Proposed Solution

IntelliHandover allows an employee to:

- Select a specific project folder.
- Give permission only to that selected folder.
- Monitor changes made within the selected project folder.
- Maintain project history and important project information.
- Organise project information into a structured knowledge base.
- Help a new employee understand the project workflow.
- Search for project files and information.
- Ask an integrated AI assistant questions about the project.
- Get explanations and summaries of project-related information.

The system is designed to **assist employees and reduce their workload**, not to replace human employees.

---

## ✨ Key Features

### 1. Secure Folder Selection
The employee chooses which project folder IntelliHandover is allowed to access.

The application does not require access to the entire computer.

### 2. Project Monitoring
The selected folder is monitored for relevant changes such as:

- New files
- Modified files
- Deleted files
- Updated project documents

### 3. Project Knowledge Base
Important project information is organised so that it can be easily understood and searched.

### 4. AI Project Assistant
The built-in AI assistant can help users with questions such as:

- What does this file do?
- Where is a particular file located?
- What is the purpose of this module?
- Explain this code or document.
- Summarise this project information.
- What was changed recently?

### 5. Employee Handover Support
A new employee can explore the available project information and understand the existing workflow more easily.

### 6. Privacy & Security
Access is limited to the project folder selected and authorised by the employee.
